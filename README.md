# SpendWise – Expense Tracker

A simple, single-page expense tracker. Add income and expenses, set a monthly budget, and see where your money goes.

## Features

- Add income and expense transactions with category, date and note
- Monthly budget with progress bar and alerts at 80% and 100%
- Spending-by-category chart for the current month
- Custom currency symbol
- Light and dark mode (follows system setting)
- Data saved in your browser (localStorage), no backend needed

## Run locally

Open `index.html` in any browser.

## Deploy with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Tech

HTML, CSS and vanilla JavaScript. No dependencies.
